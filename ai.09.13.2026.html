Model releases & capability updates

DeepSeek
DeepSeek ships V4.1-Flash, claims it beats its own flagship V4-Pro [source]
DeepSeek released V4.1-Flash on September 10, an open-weight (MIT license), multimodal mixture-of-experts model with a 552B-parameter backbone and up to 1M-token context, published simultaneously on Hugging Face and via its API. The company says independent testers found it beats the larger V4-Pro on quality, cost, and speed.
Why it matters: From September 14, DeepSeek quietly reroutes API calls to V4-Pro onto V4.1-Flash at the smaller model's price until a V4.1-Pro ships — worth knowing if any workload calls DeepSeek endpoints directly, and another data point on how fast the open-weight tier is closing on hosted frontier pricing.

Pricing / API / availability changes

OpenAI
OpenAI ends its $1/year GSA deal, moves government customers to a 50% usage discount [source]
On September 10, OpenAI and the U.S. General Services Administration announced OneGov 2.0: a 27-month, usage-based agreement (Oct 1, 2026 – Dec 31, 2028) replacing the expiring $1-per-year OneGov pilot with a 50% discount off standard token pricing, now extended beyond federal agencies to state, local, and tribal governments.
Why it matters: About 3.5 million federal employees used ChatGPT Enterprise under the $1 pilot; the shift to metered, usage-based billing in government is a signal that steep introductory AI pricing is normalizing — relevant context for partners selling AI-enabled solutions into public sector alongside Microsoft's GCC/Copilot offerings.

Product & platform launches

Microsoft
Azure Copilot Observability Agent adds support for low-cost Basic/Auxiliary log tables [source]
Microsoft's Azure Monitor team shipped an update, live by September 10, letting the Azure Copilot Observability Agent read and analyze Log Analytics data stored in the cheaper Basic and Auxiliary table plans instead of only standard Analytics tables — covering high-volume sources like ContainerLogV2, AKSAudit/AKSControlPlane, and Syslog.
Why it matters: Lets teams keep AI-assisted incident investigation working after moving high-volume telemetry to cheaper storage tiers — a direct cost/ops win for partners running Azure-hosted Dynamics 365 and Power Platform environments that lean on Log Analytics for monitoring.
Anthropic
Claude Code ships plugin evals and output-style switching in a broad update [source]
On September 9, Anthropic shipped a Claude Code release adding `claude plugin eval` (scored, reproducible plugin test suites with JSON/HTML reports), `/output-style` switching that now also works over Remote Control and in headless/cloud sessions, JSON output across plugin-management commands, and a range of reliability fixes spanning CLI, VS Code, web, and Slack.
Why it matters: Plugin evals give teams a repeatable way to regression-test Claude Code plugins before rollout — useful for partners standardizing Claude-based developer tooling across a Dynamics/Power Platform delivery team.
