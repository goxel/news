Sep 27 – Sep 30, 2026

Model releases & capability updates

Anthropic
Claude Sonnet 5.5 released [source]
Anthropic released Claude Sonnet 5.5 on September 28, describing it as a clear upgrade over Sonnet 5 that runs about 30% faster and costs up to 30% less for most work. Reported list pricing is unchanged from Sonnet 5 at $2/$10 per million input/output tokens; savings come from more efficient tool-call batching.
Why it matters: Sonnet 5.5 is already generally available in Microsoft Foundry (Global Standard and US Datazone deployments) and in GitHub Copilot, so partners can evaluate it in Azure-hosted agent builds right away.
OpenAI
GPT-6.1 Sol introduced at DevDay 2026 [source]
At DevDay on September 29, OpenAI unveiled GPT-6.1 Sol, an upgrade to GPT-6 Sol focused on agentic coding, computer use and professional work, pitched as near-Astra intelligence at about a fifth of the price. It shipped alongside 20+ other launches, including a faster Ultrafast speed tier.
Why it matters: A cheaper near-flagship model changes cost math for Azure OpenAI / Foundry-based Copilot Studio and Power Platform agent scenarios once it lands there; watch for Azure availability.

Pricing / API / availability changes

AWS / xAI
Grok 4.7 now available on Amazon Bedrock [source]
AWS announced on September 28 that xAI's Grok 4.7 is available on Bedrock with a 500K-token context window, text and image input, and four configurable reasoning-effort levels, via the Responses, Chat Completions and Converse APIs.
Why it matters: Another frontier model choice on the AWS side; relevant mainly for clients weighing multi-cloud model strategies against Azure Foundry.
OpenAI
ChatGPT Pro 500 tier, Agents API with computer use, and Decisions API announced [source]
OpenAI added a $500/month ChatGPT Pro 500 plan with the highest usage allowance and access to Ultrafast, and announced developer offerings including an Agents API with computer use and a Decisions API.
Why it matters: New agent-oriented APIs and plan changes affect budgeting and integration choices for partners building custom agents alongside Copilot Studio.

Product & platform launches

OpenAI
“Dots” always-on agents arrive in ChatGPT; Codex now runs in the cloud [source]
Dots are persistent agents, each powered by GPT-6 Astra on its own cloud computer, connecting to 4,000+ apps plus Slack and Teams; rollout began for Pro and Business Premium users (Europe delayed for Pro). OpenAI also launched ChatGPT Spaces for shared team workspaces and cloud-based Codex tasks startable from any device.
Why it matters: Direct overlap with Microsoft's new Copilot Autopilot and Copilot Studio agents; some coverage references Microsoft Agent 365 for managing dots, a governance point worth tracking.
NVIDIA
NVIDIA launches Open Agent Safety Platform [source]
Announced September 28 with 100+ partners, the platform pairs open-source OpenShell (a sandboxed runtime controlling an agent's files, tools, network and credentials) with Sentry, an out-of-band watchdog on BlueField-4 DPUs that can quarantine agents in milliseconds. Salesforce integrated OpenShell with Slack for approving agent permission requests.
Why it matters: Reinforces the industry shift toward enforced agent guardrails, the same concern D365 / Power Platform clients raise when deploying autonomous agents.
