Model releases & capability updates

Anthropic
Claude Fable 5.1 and Claude Mythos 5.1 launched [source]
Anthropic shipped Claude Fable 5.1, available to all users, and Claude Mythos 5.1, limited to U.S. trusted-access participants, calling them its most advanced models yet for coding and knowledge work. Fable 5.1 is priced roughly 25% lower than Fable 5 for typical token-billed workloads due to reduced cache-read pricing.
Why it matters: Microsoft 365 Copilot and Copilot Studio have been adding Claude as a selectable model, so a new frontier Claude release with a meaningful price cut directly affects the cost/performance tradeoffs partners make when configuring multi-model Copilot Studio agents or Azure AI Foundry deployments.

Product & platform launches

OpenAI
ChatGPT for Healthcare adds Epic EHR integration and a Healthcare Public Data plugin [source]
OpenAI announced that healthcare organizations can now connect Epic EHR environments to ChatGPT for Healthcare, alongside a new Healthcare Public Data plugin (available in ChatGPT and Codex) linking nine read-only public healthcare data sources such as PubMed, ClinicalTrials.gov, and RxNorm.
Why it matters: Limited direct Power Platform/D365 relevance, but it signals OpenAI pushing deeper enterprise system-of-record connectors (Epic) using the same LOB-system-to-grounded-connector pattern Copilot Studio partners build for Dynamics 365, making it a useful competitive reference point.
Perplexity
Hybrid Compute on Mac splits agent tasks between cloud and on-device models [source]
Perplexity launched Hybrid Compute for its Mac app, routing Perplexity Computer agent tasks between cloud frontier models and a local on-device model for sensitive files. It shipped alongside PII-TRACE, an open benchmark and dataset, and a 0.6B-parameter on-device classifier that flags personal data before it leaves the device.
Why it matters: Not directly D365/Power Platform-relevant as a consumer Mac app, but the local-model data-gating-before-cloud-escalation pattern mirrors the data-loss-prevention story Microsoft partners must tell around Copilot and Dataverse governance.

Enterprise Frontier Safeguards pairs zero data retention with customer-controlled monitoring [source]
Anthropic introduced Enterprise Frontier Safeguards, combining zero data retention with misuse-detection monitoring that runs inside infrastructure the customer controls rather than Anthropic's own cloud. The move follows enterprise customer pushback on prior data-handling terms.
Why it matters: Data residency and control is a recurring blocker when pitching Copilot/agent solutions into regulated D365 customers (finance, healthcare, government); a customer-controlled-infrastructure, zero-retention model gives partners a concrete talking point versus Copilot's own data-handling commitments.
