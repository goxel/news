Aug 12 – Aug 16, 2026

Model releases & capability updates

Google
Gemini 3.7 Flash launches as new coding/agent workhorse model [source]
Google shipped Gemini 3.7 Flash just three weeks after 3.6 Flash, with sizeable gains on coding benchmarks (debugging, issue resolution, production-ready code generation) and an introductory price of $0.75/1M input and $3.75/1M output tokens through year-end.
Why it matters: A cheaper, faster Gemini tier raises the bar for the agentic-coding and workflow-automation tools Power Platform and Copilot Studio compete with on cost and latency.
xAI
Grok 4.6 ships as new flagship, tuned for long-running agents [source]
xAI released Grok 4.6, built for long-running agentic and multi-step tasks (research, coding, building artifacts). It roughly matches GPT-5.6 Sol on the Artificial Analysis Intelligence Index at $2/$6 per million input/output tokens.
Why it matters: Confirms the frontier-agent race is now priced aggressively; worth tracking as a lower-cost option surfaces inside developer tools your team already uses (see GitHub Copilot item below).
Alibaba / Qwen
Qwen3.8-27B open-weights model released under Apache 2.0 [source]
Alibaba's Tongyi Lab released Qwen3.8-27B, a 27.8B-parameter multimodal model with a 262K native context window, runnable on a single 24GB-VRAM GPU, and licensed for unrestricted commercial use.
Why it matters: A capable, self-hostable open model lowers the bar for competitors building private/on-prem AI features that bypass Azure-hosted Copilot services.

Pricing / API / availability changes

OpenAI
"Ultrafast" preview runs GPT-5.6 Sol at up to 14x normal speed [source]
OpenAI began a limited API preview of Ultrafast, a Cerebras-powered service tier that pushes GPT-5.6 Sol to roughly 750 output tokens/second — about 14x standard throughput, aimed at voice, support, and other latency-sensitive workloads.
Why it matters: Sets a new bar for real-time agent responsiveness; relevant if you're evaluating latency for voice/chat agents built on Copilot Studio or Azure AI Foundry.

Product & platform launches

Microsoft
Microsoft begins merging Copilot and Microsoft 365 Copilot into one app [source]
A worldwide rollout of a single, unified "Microsoft Copilot" app (mobile and web first, Windows/Mac in mid-September) began this week, supporting personal, work, and school accounts side by side while retaining enterprise data controls. Consumer Podcasts, Group Chat, and Deep Research are being retired starting Aug 18 as part of the consolidation.
Why it matters: Directly affects how end users in your customers' tenants access Copilot day-to-day — worth flagging to admins ahead of the Aug 18 feature retirements and account-switching changes.
xAI
Grok 4.6 lands in GitHub Copilot across eight dev surfaces [source]
Two days after its release, Grok 4.6 became selectable in GitHub Copilot's model picker in VS Code, Visual Studio, JetBrains, Xcode, Eclipse, the Copilot CLI, cloud agent, and app, across Pro, Business, and Enterprise plans.
Why it matters: Gives developers on Microsoft's own tooling a non-Microsoft, non-OpenAI model option inside Copilot — a data point on how open the GitHub Copilot model marketplace is becoming.
Google
Gemini's "Take Notes for me" now covers in-person meetings [source]
Google Meet's Gemini-powered note-taking, previously limited to video calls, now works for in-person meetings too: it captures a structured summary, action items, and full transcript into a Google Doc, saved to Drive. Web rollout began Aug 14.
Why it matters: Direct competitive overlap with Copilot's meeting-recap features in Teams — useful context when positioning M365 Copilot against Workspace.
