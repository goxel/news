Model releases & capability updates

Alibaba / Qwen
Qwen3.8-Omni-Flash ships with 1M-token context and steep audio/video price cuts [source]
Alibaba's Qwen team released Qwen3.8-Omni-Flash, a natively omnimodal model handling text, image, audio and video in one pass, with a 1M-token context window and built-in agentic tool-calling. Alibaba reports a 26%+ average score gain across 30 evaluations versus Qwen3.5-Omni-Plus, with audio-input costs down more than 98% and combined audio-video costs down more than 93%; it's closed-weight, available via Qwen Chat, QwenCloud and an OpenAI-compatible Model Studio API.
Why it matters: A general competitive signal on frontier multimodal pricing and capability outside the Microsoft/OpenAI stack — useful context when clients ask about model options for agentic or multimodal workloads.

Pricing / API / availability changes

OpenAI
ChatGPT for Microsoft Word reaches general availability [source]
OpenAI made ChatGPT for Microsoft Word generally available across all plans, including Free, adding a sidebar that uses the open document as context for drafting, summarizing, rewriting and formatting. The same release added Chrome extension support inside the ChatGPT desktop app's built-in browser and multi-account support for plugins; ChatGPT for Word will be on by default in workspaces starting October 1, 2026.
Why it matters: A native ChatGPT add-in inside Word puts OpenAI directly on the Office surface where Microsoft 365 Copilot already competes — worth having a point of view ready for clients comparing the two.
Anthropic
Claude Code adds AGENTS.md support and reworks Auto-mode billing on Bedrock, Vertex and Microsoft Foundry [source]
Claude Code v2.1.277 added support for reading AGENTS.md project instructions when no CLAUDE.md is present. v2.1.278 changed Auto mode for API/Enterprise users — including on Bedrock, Vertex and Microsoft Foundry — to default to a server-side classifier that isn't billed for classifier overhead, with an opt-out for gateway deployments.
Why it matters: Directly touches Microsoft Foundry-hosted Claude Code deployments, and the AGENTS.md convention affects how dev teams structure instructions across coding agents.

Notable research or safety news

Microsoft
Microsoft patches maximum-severity (CVSS 10.0) Azure AI Foundry privilege-escalation flaw [source]
Microsoft disclosed CVE-2026-85889, a missing-authentication vulnerability in Azure AI Foundry (Microsoft Foundry) that could let an unauthenticated network attacker escalate privileges. The flaw was fixed server-side; Microsoft says no customer patching or configuration changes are required and has no evidence of exploitation.
Why it matters: Azure AI Foundry underpins Copilot Studio and custom Azure OpenAI-based agents that Power Platform/D365 partners build on — worth flagging to clients even though no action is needed on their end.

Anthropic published three self-reported measurements of AI development pace inside the company: Claude leads 26% of model R&D work as of August 2026 (up from under 1% in February), plus new metrics on oversight of roughly 30,000 internal agents and how compute is split between safety and other work. Anthropic states Claude is not operating fully autonomously on any measured R&D task.
Why it matters: Concrete, vendor-disclosed metrics on how fast frontier AI capability and agent autonomy are advancing — useful context for clients' AI governance and agent-oversight conversations.
Cross-vendor (Anthropic, OpenAI, Microsoft, Google)
"Plugin4Shell" zero-click RCE flaw disclosed across Claude Code, Codex, GitHub Copilot and Gemini CLI [source]
Security firm AIR Security disclosed Plugin4Shell, a zero-click RCE flaw that breaks SHA-pinning protections across four major AI coding agents, letting a malicious plugin update run attacker-controlled code without user action. Anthropic (Claude Code v2.1.179) and OpenAI (Codex v0.146.0) shipped fixes before disclosure; Google deprecated the affected Gemini CLI instead of patching it, and GitHub Copilot remained unpatched at disclosure.
Why it matters: GitHub Copilot — widely used by Microsoft partner developers on D365/Power Platform projects — was unpatched at disclosure, making this an active exposure worth tracking until a client-side fix ships.
